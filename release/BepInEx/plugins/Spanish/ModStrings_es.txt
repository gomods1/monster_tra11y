# Spanish for the Monster Train accessibility mod's own speech.
# The mod builds its sentences in English; every spoken string is translated
# with these rules just before it reaches the screen reader.
#
#   English template => Spanish template
#   ~ english phrase => frase        (whole words left over in game text)
#
# {name} = any text, {#name} = a number. A rule covers whole segments: it starts
# at the text start or after ", " ". " ": " "; " "! " "? " " - " "(" or a newline,
# and ends before , . : ; ! ? ) " (" " - " or a newline. The longest match wins.
# Only the first letter is matched without case. A single trailing period is
# ignored. The first rule for an English template wins; later duplicates are ignored.
# Edit freely: the file is read when the game starts.
