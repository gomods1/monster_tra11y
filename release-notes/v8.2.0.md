# Monster Train Accessibility v8.2.0

Small reading fixes.

- **Boss intents**: at the start of each turn, a boss's intent is announced when it is new or has changed, for example "Talos, the Architect intent: destroy the room after combat, targeting bottom floor". Before, you only heard it by checking with K or Shift+L.
- **Artifact triggers**: say what the artifact did, using the game's own popup text (for example "Retribution: Spikes 3"), instead of just "Retribution triggered". Artifacts with no popup text still say "triggered".
- **Shops**: the merchant character reads as "Merchant of Steel. Press Enter to talk" instead of "Merchant Screen". Enter makes the merchant talk, as in the game.
- **Draft skip buttons**: "Skip (+25)" now says "Skip (+25 gold)".
- **Card and event text**: no more stray "X" in texts like "Gain 40 X gold", and no more ".," in boss intents.
