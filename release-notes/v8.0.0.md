# Monster Train Accessibility v8.0.0

A big usability release: every mod key moved off the game's own keys, combat narration is back and much more complete, a new settings menu, spoken scene descriptions, and many screens that were silent or confusing now read properly.

## Keys changed (no more clashes with the game)

Some mod keys also triggered game actions: C re-read the focused item **and** opened the discard pile, V cycled verbosity **and** opened the consumed pile, and so on. Every mod key is now a key the game does not use. Existing installs are migrated automatically; keys you rebound yourself are kept.

| Action | Old | New |
|---|---|---|
| Re-read the focused item | C | F2 |
| Read all text on screen / run summary | T / S | F3 |
| Cycle verbosity | V | F4 |
| Gold | Ctrl+G | F5 |
| Pyre health | Ctrl+H | F6 |
| Pact shards and threat | Ctrl+R | F7 |
| Accessibility settings | - | F9 (new) |
| Read hand | H | J |
| Read all units in detail | U | Shift+L |
| Read ember | R | G |
| Open floor review | Up arrow | Shift+K |
| Re-read map node | M | F2 |

K (selected floor), L (all floors), F1 (help) and Ctrl+arrows (review buffers, map cursor) are unchanged.

## Settings menu (F9)

A spoken list of every mod option, on any screen: what gets announced, the combat summary, scene descriptions, verbosity, braille, and every key. Up and Down choose, Left, Right or Enter change, F2 reads the description, Escape closes. To rebind a key, press Enter on it and then the new key - game keys are refused. Changes save immediately.

## Scene descriptions (new)

Short spoken descriptions of the moments sighted players watch: the game launching, a run starting, arriving at each ring of Hell, a boss's entrance, a boss turning Relentless, a boss falling, the Last Divinity acting from outside the train, and the end of a run. Never during combat (a boss turning Relentless is described at the start of your next turn). Toggle them in F9. The texts are in `SceneDescriptions.txt`; put an edited copy next to the mod DLL in `BepInEx/plugins` to override them.

## Combat

- Live narration is back by default. The combat summary from the previous release is now an option (F9), off by default.
- Each turn starts with one line: "Your turn, 3 ember, 5 cards in hand, 2 waves remaining". Before, there was no turn-start announcement at all, and the wave counter never worked.
- New announcements:
  - your own units being summoned
  - unit abilities triggering (Summon, Slay, Revenge, Resolve, Extinguish, Immune, "No attack", "Can't move boss"...)
  - cards added to your hand, draw or discard pile mid-battle (Scourges, Sinner's Burden, "add to hand" effects)
  - "choose a card" prompts
  - healing with the real amount (no more "healed for 5" at full health)
  - ember gained mid-turn
  - gold gained or spent
  - pact shards gained, spent or used
  - attack buffs and debuffs
  - your units changing floors
  - floor capacity changes
- Pyre hits name the attacker: "Reconciler hits the pyre for 1, 43 left".
- Identical events in the same moment are said once with a count: "Clergyman gains Rage 2, 3 times".
- Status effects report what actually changed: nothing is announced when a unit is immune, and "remove all" removals are counted.
- "Enemy turn" is only said after combat, not when you end your turn.
- Battle start is one short line: "Battle started, pyre 54 of 80, 3 waves remaining". The enemy's battle artifact is read as "Enemy artifact: ..." instead of being announced as a reward.
- Cards in hand say their position ("Frozen Lance, 1 ember, 2 of 5").
- Enemies' trigger abilities are called "Ability", not "Intent"; only bosses have intents.
- Removed noise:
  - focus readouts the game triggers on its own during combat
  - the ember counter being read at battle start
  - duplicate pyre damage lines
  - upgrade buffs on freshly summoned units
  - the Last Divinity pyre's fixed traits at every battle start
  - misleading boss movement previews
- Several dedup bugs fixed: hits on two enemies with the same name are no longer dropped.

### Combat summary (option)

When on, automated combat stays quiet and one summary is spoken right before your turn: per floor, the damage your units dealt and took, kills, losses and the health left on every unit that was hit, then enemy moves, pyre damage and new arrivals.

## Screens

- The screen tracker now follows the screen that actually has focus. Before, leaving a shop, event, reward or pile view left the mod thinking it was still there, which gave the wrong help and broke map reading.
- **Map**: stops say their path, ring and whether you can visit them ("Merchant of Steel, left path, available, ring 2"); battle nodes name the battle. The minimap (M) reads every stop and battle with its ring.
- **Dialogs**: confirmation dialogs (start battle with unclaimed rewards, erase run...) are read when they open, and their default button is announced.
- **Main menu**:
  - The Standard Run dialog reads your saved run: clans, champion, covenant, ring, pyre, gold.
  - Challenge mode buttons say which mode they start.
  - "Patch Notes" is no longer read as a dialog.
- **Clan selection**: the covenant rank reads properly ("No Hellhorned and Stygian Guard wins yet").
- **Run start**: the boss list is one short line; each boss is in the review buffer (Ctrl+Up). Ctrl+arrows there read the bosses instead of moving the map cursor hidden behind the list.
- **Rewards**:
  - Reward icons read as "Gain 50 gold", "Clan Pack".
  - Picking a card says "X added to your deck"; gaining an artifact says "Artifact gained: X".
  - No more empty "Rewards" announcements under drafts, upgrades and the Hellvent.
- **Deck and upgrade screens**: card positions follow the grid on screen ("Card 1 of 18").
- **Champion upgrades** name the path ("Penumbra upgraded: Glutton").
- **Boss intros** say "Boss battle"; the trial toggle is called Trial.
- **Run end**:
  - A defeat no longer says "VICTORY!".
  - Score rows read their name and breakdown instead of "+5000".
  - The pact crystals row and covenant icons read properly, and dates are readable.
- **Run History**: every row used to read the same placeholder date. Rows now read result, clans, run type, covenant, battles won, score and date.
- Toggles (like The Last Divinity on the main menu) announce their new state after Enter.
- Speech text is cleaned up: no more "gold ." or "stack.Decreases" from stripped icons.

## Help (F1)

- Accurate battle and map help (the map help described keys that did nothing).
- Entries say their position ("3 of 30"), Home and End jump, and every screen's list ends with the keys that work everywhere.

## Fixes

- The mod could shut itself down right after the game started (its patches were removed when the plugin object was destroyed). It now stays active.
- Many smaller reading fixes across screens.

## Download

Each release has the mod zip and the installer (MonsterTrainAccessibilityInstaller.exe), which is now attached to every release.

## For developers

- New debug bridge (off by default, `Debug.Bridge` in the config) to drive the game from a command file without window focus, with all speech logged to a file. See CLAUDE.md.
- CLAUDE.md updated, including the corrected floor numbering (room index 0 is the bottom floor).
